# Financial Analysis Dashboard | Microsoft Excel

## Project Overview

This project focuses on analyzing financial and sales data using Microsoft Excel. The goal was to transform raw business data into meaningful insights through data analysis, KPI development, Pivot Tables, and dashboard visualization.

The dashboard provides an overview of financial performance across different months, products, business segments, countries, and discount categories.

## Key Performance Indicators (KPIs)

The dashboard tracks the following business metrics:

## Business Analysis

The dashboard covers the following areas:

### 1. Monthly Financial Performance
- Monthly Revenue Trends
- Monthly Profit Trends
- Comparison of revenue and profit over time

### 2. Product Performance
- Sales distribution across products
- Identification of top-performing products

### 3. Segment Analysis
- Profit contribution by business segment
- Comparison of profitability across segments

### 4. Geographical Analysis
- Country-wise profit comparison
- Identification of high-performing markets

### 5. Discount Analysis
- Discount distribution by discount band
- Comparison of discount categories

## Key Metrics & Formulas

**Profit**

Profit = Revenue - COGS

**Profit Margin**

Profit Margin = (Total Profit / Total Revenue) × 100

**Revenue**

Revenue = Unit Price × Units Sold

## Key Takeaways

The dashboard provides a way to:
- Monitor overall financial performance.
- Compare monthly revenue and profitability.
- Evaluate product and segment performance.
- Identify geographical differences in profitability.
